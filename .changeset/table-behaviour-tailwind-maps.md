[component] `Table` behaviour comes from precompiled Tailwind utility classes: the sort button and its indicator, the filter trigger and its inline slot, the selection column, the table element itself, the scroll region that bleeds to a container's edges, and the empty cells a windowed body or a windowed column set keeps the place of. A windowed gap cell carries its size in an inline `--_table-gap-block-size` / `--_table-gap-inline-size` variable and a class reads it, so its place is still exact. Sorting, filtering, selection and windowing look and behave as before.
