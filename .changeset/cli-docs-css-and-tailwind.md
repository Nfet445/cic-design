[docs] Документация для тех, кто собирает интерфейс на Astryx, описывает настоящее состояние: компоненты несут литеральные utility-классы из предсобранного stylesheet, токены — это CSS-переменные темы, `className` дописывается после классов компонента и побеждает, `xstyle` остаётся временным выходом для правила, которое должно победить. Справочник `css-and-stylex` заменён на `css-and-tailwind`, овервью объясняет слои `reset`, `astryx-base` и `astryx-theme`, примеры `styling-basics` используют публичные импорты, а страница `tokens-and-setup` называет stylesheet, который нужно импортировать.

Проба стилей в агентской документации теперь ищет импорт `@astryxdesign/core/astryx-tailwind.css` и возвращает `tailwind` раньше проверки компилятора StyleX; проект без этого импорта по-прежнему распознаётся как `stylex`.
